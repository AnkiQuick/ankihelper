# Ankihelper (anki划词助手)

This application was developed by [mmjang](https://github.com/mmjang), but since 2021, development has been inactive. Despite this, I still find it a great tool, so I want to continue maintaining it.

I am not an Android developer, so initially, even though I wanted to maintain it, I lacked the necessary expertise. However, thanks to AI, I can code without requiring extensive programming knowledge.

Initially, I used [zed](https://github.com/zed-industries/zed) to perform some work, upgrading outdated packages to make it run on modern Android. Since 2025, there are several advanced tools such as claude code/gemini code/qwen code that work very well.

I have restarted the journal to improve this application.
